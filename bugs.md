# Mobile App

## Push Notification feature
- Build  a complete push notification feature for the mobile app.
- the notifications should be based on the settings in the settings screen.
- Send morning overview and night recap of what was done and what needs to be moved.
- Reminders before meetings, appointments, and other scheduled events.
- Reminders for events in year at a glance.
- Reminders/notifications for an activity that is about to start.
- Reminders for activities that are past their ETA and need to be updated their status.
- Reminders for meetings that are past their ETA, asking user to update the status and takeaways.
- Read: priority-manager-spec.md for more details.
